Como jogar?
Objetivo: Descobre a palavra secreta de 5 letras escondida entre duas palavras ordenadas alfabeticamente.

Modos:
• Diário: Uma palavra por dia. Todos têm a mesma palavra. Podes jogar apenas uma vez por dia.
• Livre: Gera palavras aleatórias. Joga quantas vezes quiseres.

Intervalo: A barra mostra o espaço restante. As percentagens indicam a distância até à palavra secreta.

Teclado inteligente: A linha de letras mostra apenas as letras possíveis para cada posição.

Validação: Tens 12 tentativas. As palavras são validadas por IA.
